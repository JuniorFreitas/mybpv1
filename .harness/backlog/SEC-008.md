# SEC: SEC-008 — Isolamento frouxo via pivot `cliente_funcionarios`

## Descrição
`ScopeClientesEmpresa` confiava em `auth()->user()->ClienteFuncionarios->first()` sem validar se o cliente pertence a `ClientesEmpresa`. Pivot órfão/sujo podia restringir queries a `cliente_id` de outro tenant (vazamento) ou esconder dados legítimos.

Relacionado: BUG-004 (`getUsuario` + `area_id`); global scope `Cliente::scopeCliente` quebrava com `auth()` null.

## Severidade
High

## Evidência
- `app/Scopes/ScopeClientesEmpresa.php` (e espelho `app/Tenant/Scopes/ScopeClientesEmpresa.php`)
- Uso ativo: `app/Models/PesquisaClimaCliente.php` (`addGlobalScope`)
- Caso real userId 50393: pivot `cliente_id=60331` fora de `ClientesEmpresa` (empresa 104)
- `app/Models/Cliente.php` `scopeCliente` lia `auth()->user()->ClientesEmpresa` sem null-check

## Impacto
Modelos com `ScopeClientesEmpresa` podiam listar/filtrar por cliente de outro tenant se o pivot estivesse inconsistente. Guest HTTP em `Cliente` podia gerar exception em vez de fail-closed.

## Possibilidade de exploração
Pré-condição: registro em `cliente_funcionarios` apontando para cliente fora de `empresa_clientes` (dado sujo, sync antigo ou bug de cadastro). Não exige IDOR por request; basta sessão autenticada com pivot inválido.

## Recomendação
1. Intersectar pivot com `ClientesEmpresa` antes de filtrar por um único `cliente_id`.
2. Fail-closed para guest HTTP / lista vazia (`whereRaw('0 = 1')`).
3. `getUsuario`: null-safe no scope (`?->Cliente?->area_id ?? 0`), sem `withoutGlobalScopes` no pivot.
4. Testes unitários de isolamento + regressão `UsuarioAutenticadoTest`.

## Status de correção
Corrigido

## Bypass legítimos revisados (não corrigir sem redesign)
- Jobs/mails/APIs públicas: `Cliente::withoutGlobalScopes()->find($empresaId)` com ID de contexto (assinatura, carta oferta, WhatsApp).
- `ControleExameController::getFichaPdf`: token público + `whereToken` (não é filtro por `empresa_id` do auth).
- Residual R6/TD-003: demais `withoutGlobalScopes` em integrações SPA/vagas públicas — manter disciplina manual + heurística.
