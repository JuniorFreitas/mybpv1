# TASK: UPG-001

## Título
Spike: inventário de compatibilidade PHP 8.5 + Laravel 13

## Tipo
Spike

## Objetivo
Mapear bloqueadores de upgrade (Composer, extensões PHP, breaking changes Laravel 13, serviços Docker) antes de implementar a imagem e o bump de framework.

## Contexto
Demanda L3 de subir MyBPIN para Laravel 13 + PHP 8.5 com imagem própria. Discovery em `.harness/discovery/UPG-L13-PHP85.md`.

## Descrição
- Rodar análise `composer why-not` / resolução dry-run para `php:8.5` e `laravel/framework:^13`
- Listar pacotes de risco (`intervention/image`, `predis`, `juniorfreitas/phpquery-laravel`, Horizon, Reverb, Excel, DomPDF, activitylog)
- Inventariar uso de `VerifyCsrfToken`, cache de objetos, `upsert`, helpers `array_first`/`array_last`
- Confirmar extensões PHP realmente usadas em produção vs carregadas hoje
- Entregar relatório curto com go/no-go e ordem de remediação
